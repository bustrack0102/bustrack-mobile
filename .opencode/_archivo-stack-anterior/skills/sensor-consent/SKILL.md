# sensor-consent

## Cuándo usar

Se trabaja en `specs/funcionalidades/calificaciones-acelerometro/`.

## Pasos

1. Diseñar consentimiento revocable.
2. Capturar y anonimizar lotes.
3. Definir contrato con la API.

## Prohibido

- Copiar patrones de otro stack sin adaptación.
- Declarar recursos o endpoints inexistentes.
- Introducir secretos o PII.
