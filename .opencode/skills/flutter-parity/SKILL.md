# flutter-parity

## Cuándo usar

Se trabaja en `specs/03-migracion-de-kotlin-a-flutter/`.

## Pasos

1. Inventariar flujos Kotlin.
2. Definir arquitectura Flutter.
3. Probar paridad de login/sesión/logout.

## Prohibido

- Copiar patrones de otro stack sin adaptación.
- Declarar recursos o endpoints inexistentes.
- Introducir secretos o PII.
